# Sway

Sway is a mini social media platform that allows users to create
posts, interact with other users, comment on posts, search users
and posts, and manage their profiles.

## Features

- User registration and login
- User authentication
- Create and view posts
- Comments
- User profiles
- Search functionality
- Image uploads
- MongoDB database
- REST API

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## Project Structure

Sway/
├── backend/
└── frontend/

## How to Run

1. Install dependencies:
   npm install

2. Configure your environment variables.

3. Start the backend server.

4. Open the frontend in your browser.
